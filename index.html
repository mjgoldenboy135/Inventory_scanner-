  1. Create a GitHub repo (e.g. my-gtin-db) and make it public
  2. Add a file named products.json with content: {"products":[]}
  3. Generate a Personal Access Token with repo scope (for adding products)
  4. Fill in Owner, Repo, and PAT above → click Connect
  5. Others can read without a PAT; only writers need one
